# UC2000KeyboardLion

This is a Lion-branded fork of the original `UC2000Keyboard` Android app.

The original project remains unchanged in the sibling directory:

- `tools/keyboard-emulator/UC2000Keyboard/`

This fork adds:

- a different Android application id so it can coexist with the original app
- `Lion` in the app name
- menu actions for `Upload BIN` and `Upload BIN + Run`
- one-way BIN transfer based on the UC2000 transmitter protocol

Important:

- the copied legacy APK from the original project was removed from this fork
- this fork must be rebuilt to produce a new APK
- transfer reliability still depends on the phone speaker / watch coupling
